# CancerHLA-I: Cancer Immunotherapy and HLA Database

CancerHLA-I is a comprehensive web-based resource developed to study the role of HLA class-I alleles, neobinders, cytokines, and immune responses in cancer immunotherapy and patient survival.

Web Server: https://webs.iiitd.edu.in/raghava/cancerhla1/

## About the Database

CancerHLA-I was developed to help researchers and clinicians explore the relationship between genomic immune profiles and cancer patient survival. The platform integrates HLA-I alleles, neoantigen binders, cytokine expression, and clinical survival information across multiple cancer types.

The database contains:

- **8346 cancer patients**
- **20 cancer types**
- **352 HLA class-I alleles**
- **660,959 tumor-specific HLA-I neobinders**
- **153 cytokines and immune markers**

Data were collected and processed from:

- TCGA
- TCIA

---

## Key Features

- Survival analysis based on HLA-I alleles
- Neoantigen and neobinder analysis
- Cytokine expression profiling
- Cancer-specific prognostic biomarker discovery
- Interactive search and browse options
- User-friendly web interface

## Applications

CancerHLA-I can be used for:

- Cancer immunotherapy research
- Personalized cancer treatment studies
- Neoantigen analysis
- Biomarker identification
- Immune response analysis
- Survival prediction studies
